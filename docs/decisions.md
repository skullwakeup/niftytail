| D30 | Day-5 GPD core: estimator and numerical conventions | (1) Excesses y = L − u > 0 (strict, Day-4 exceedance mask); G(y; ξ, β) = 1 − (1 + ξy/β)^(−1/ξ), β > 0, ξ = 0 limit 1 − exp(−y/β), location 0; scipy `genpareto(c=ξ)` has the same sign (`genextreme` does not). (2) `excesses(losses, u)` = losses[losses > u] − u; 1-D finite inputs; messages without values. (3) NLL = +∞ if β ≤ 0 or non-finite, ξ ≤ −1, or any 1 + ξy/β ≤ 0; with z = y/β: n ln β + Σz if \|ξ\| < xi_zero_tol (1e-8, [threshold]); else n ln β + Σ log1p(ξz)/ξ + Σ log1p(ξz).
